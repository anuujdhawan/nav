# Blog Keyword Research Tracker

Central repository of researched keywords for blog content planning.

**Primary target keyword:** `immigration consultant dubai`

## Research Integrity

Every keyword below was validated against live sources (2026): government portals, competitor pages that rank for the phrase, and case-study position data. The **Source** column records where the keyword/search intent was observed. Only add keywords that came from actual research (web search, competitor SERP analysis, keyword tools), not invented phrases.

## How to Use This File

- Add newly researched keywords to the relevant cluster section below.
- Keep one keyword per row; set a `Status` of `published` when a blog is live.
- When a blog is published, move the keyword to the **Covered** section.
- Competition: `low` = few/no strong competitors, `low-moderate` = winnable with good content, `moderate` = needs content + internal links + authority.
- Research rounds: Round 1 = consultant/blue-collar/cost/trust/comparison keywords; Round 2 = Australia/UK/Canada/Golden Visa from UAE keywords.
